# Releasing

Release automation is not active yet because the remote repository has not been
created.

## Bootstrap release checklist

Before the first release flow is enabled:

1. Create and configure the remote repository.
2. Verify a clean clone resolves the Boyan module and Beads state correctly.
3. Run the local checks from [CONTRIBUTING.md](CONTRIBUTING.md).
4. Confirm the active Prism story has advanced beyond bootstrap-only scaffold.

Until those conditions are met, treat this repository as pre-release.
